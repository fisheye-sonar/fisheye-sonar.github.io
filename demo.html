Upload a short ARIS or DIDSON file and see how FishEye helps prepare annotations for your existing workflow. You stay responsible for reviewing, validating, and correcting the results.

Open the FishEye cloud demo

Sign in with your email address and access code. If you do not have a code, you can request one from the demo login page.

Launch cloud demo ->
The cloud demo supports one user at a time and a small number of files. It is intended only to demonstrate the capabilities of the FishEye desktop apps. FishEye accelerates annotation; it does not replace expert review. All outputs should be reviewed, validated, and corrected. For private data, repeatable processing, and batch file processing, use the desktop app.
