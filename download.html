Before you install

System requirements

FishEye is designed to fit into experts' existing workflows. These are the current platform notes for the release builds.

macOS
Apple Silicon Mac required: M1, M2, M3, or M4. Intel Macs are not supported by the current build.
Windows
Windows field stations are supported. A dedicated GPU is recommended for faster processing. The installer can download additional files for GPU acceleration.
Internet
An internet connection is required on the first run to download the model weights, and again when updates are available. Windows also downloads the files needed for GPU acceleration. After the initial downloads, an internet connection is not required for local processing.
Input files
ARIS and DIDSON sonar files. Outputs are prepared for existing ARISFish workflows, where they can be validated and corrected.
